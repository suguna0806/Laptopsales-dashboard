💻 Laptop Sales Dashboard

📌 Project Overview

The Laptop Sales Dashboard is an interactive data visualization project created using Microsoft Power BI. It provides a clear and insightful view of laptop sales data, helping users understand sales performance, product distribution, companies, operating systems, RAM, display sizes, and graphics types.

🎯 Objectives

- Analyze overall laptop sales performance.
- Compare sales across different companies.
- Understand product distribution by laptop type.
- Analyze the number of products based on operating systems.
- Compare RAM specifications with display sizes.
- Analyze products based on graphics types.
- Provide an interactive and easy-to-understand dashboard.

🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Excel / CSV Dataset

📊 Dashboard Features

1. Total Sales

Displays the overall sales value of the laptop products.

2. Total Products

Shows the total number of laptop products available in the dataset.

3. Total Companies

Displays the number of different laptop companies included in the dataset.

4. Sales by Company

A chart that compares laptop sales across different companies.

5. Sales by Type Name

Shows the distribution of sales among different laptop types such as:

- Notebook
- Gaming
- Ultrabook
- 2 in 1 Convertible

6. Average RAM by Display Size

Displays the average RAM associated with different laptop display sizes.

7. Count of Products by Operating System

Shows the number of products available for different operating systems, including:

- Windows 10
- Windows 7
- Linux
- Chrome OS
- macOS
- Android

8. Products by Graphics

Visualizes the number of laptop products based on their graphics specifications.

9. Company Filter

The dashboard includes an interactive company filter that allows users to select a specific laptop brand and analyze the corresponding data.

📈 Key Insights

- Lenovo contributes significantly to the overall laptop sales.
- Notebook laptops represent a major portion of the products.
- Windows 10 is one of the most commonly used operating systems in the dataset.
- The dashboard helps compare different laptop brands and specifications easily.
- Interactive filters make it easier to analyze specific companies.
